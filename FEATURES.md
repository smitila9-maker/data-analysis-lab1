# Паспорт витрины признаков (FEATURES.md)

| Колонка | Тип | Источник | Как получена | Модель |
| :--- | :--- | :--- | :--- | :--- |
| origin_freq | float | Категория | Доля записей для аэропорта | Да |
| typecode_freq | float | Категория | Доля записей для типа самолета | Да |
| year | int | Дата | Год из столбца day | Да |
| month | int | Дата | Месяц из столбца day | Да |
| day_of_week | int | Дата | День недели (0-6) | Да |
| is_weekend | int | Дата | Флаг выходного дня | Да |
| days_since_start | int | Дата | Дней с начала наблюдений | Да |
| origin_count | int | Агрегат | Число записей в группе аэропорта | Да |
| origin_median_alt | float | Агрегат | Медиана высоты внутри группы | Да |
| altitude_deviation | float | Агрегат | Отклонение записи от медианы группы | Да |
| callsign_len | int | Текст | Длина позывного | Да |
| callsign_has_digits | int | Текст | Флаг наличия цифр в позывном | Да |
| airline_freq | float | Текст | Частота авиакомпании (префикса) | Да |
| latitude_1 | float | Числовой | Исходная широта | Да |
| longitude_1 | float | Числовой | Исходная долгота | Да |
| altitude_1 | float | Числовой | Исходная высота | Да |
| airline_prefix_len | int | Текст | Длина буквенного префикса | Да |
| latitude_2 | float | Числовой | Исходная широта (2-я точка) | Да |
| longitude_2 | float | Числовой | Исходная долгота (2-я точка) | Да |
| altitude_2 | float | Числовой | Исходная высота (2-я точка) | Да |
| target | float | Цель | Высота (altitude_1) | Нет (цель) |

*Примечание: некоторые колонки (например, year) могли быть удалены при отборе, если они оказались почти постоянными (одно значение >95% строк).*
