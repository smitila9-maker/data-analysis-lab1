# Лабораторная работа №1: Обработка и очистка данных

## Описание проекта
Проект посвящен полному циклу подготовки данных: от загрузки исходного файла до загрузки очищенного набора в реляционные базы данных (SQLite и PostgreSQL).

## Требования
* Python 3.12.14
* Poetry (для управления зависимостями)
